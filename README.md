# Tabily（旅行プランapp）

グループ旅行プラン自動生成アプリ。人数・予算・出発地・日数を入力すると、全員分の移動・合流・宿・食事を一括でプラン化する。

## 新規性

既存の旅行アプリは個人向けの提案が中心。本アプリはグループ特有の制約を同時に処理する点が新規性の核。

- **複数出発地の合流最適化**：メンバーごとの出発地から目的地ハブまでの移動時間・費用を算出し、最も遠いメンバーを基準に集合時刻を決定
- **予算の二重チェック**：グループ合計予算と一人当たり上限の両方を判定し、超過時は具体的な削減案（相部屋・食事ランク・早割など）を提示
- **移動費の割り勘公平化**：出発地による移動費の差を全員で割り勘した場合の負担額を算出
- **人数制約を踏まえた宿泊・食事手配**：人数に応じた部屋割り・予約推奨を日程に反映

## 構成

- `index.html` — 動作するプロトタイプ（サーバー不要、ブラウザで直接開ける）。現状はモックエンジンによるプラン生成
- `TabilyApp/` — Expo（React Native）によるiOS/Androidアプリ雛形
